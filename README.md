🚦 ITCS: Intelligent Traffic Control System
Edge AI-based solution for real-time traffic management on Raspberry Pi 5.
🚀 Key Highlights
Low-Light Mastery: Tích hợp Zero-DCE++ & SCI giúp hệ thống hoạt động chính xác trong điều kiện ban đêm/ngược sáng.

High Performance: Tối ưu hóa trên Raspberry Pi 5 đạt tốc độ xử lý thời gian thực nhờ framework NCNN.

Ultra-Lightweight: Kiến trúc SimpleCNN (0.251M params) giúp phân tích mật độ giao thông mà không tiêu tốn tài nguyên
